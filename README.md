# ComcastAutomations

SalesforceScrape.py - Opens an edge client that automanously scrapes data from Polaris2 Salesforce 

ExportLOBreport.vb - VBA script that takes the analyst semantic file and turns it into a data only report that is smaller in size and more user friendly

ResidentialIRR.vb - VBA script that inputs variables into LEM model to get back IRR percentages for jobs

RunResi_IRR.ts - the same as ResidentialIRR.vb but in TypeScript

MPRauto.py - Script that scrapes P2 for all necessary data and aggregates it into one file for reporting

TBAPIpull - automatously downloads data from Tableau API
